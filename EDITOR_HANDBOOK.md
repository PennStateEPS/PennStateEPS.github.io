# IEEE EPS Penn State — 1-page editing handbook for future committee members

**Your daily website editor is Storyblok, not GitHub.** Sign in to the chapter's Storyblok workspace using your own authorized account. Never share the GitHub or Storyblok owner password.

## Simple tasks

- **Change a heading, button, photo, or link:** Content → Home → select the appropriate Body block → edit the field → Save → Publish.
- **Move an entire page section:** Content → Home → Page → Body → grab the handle to the left of the block → drag → Publish.
- **Add a committee member:** Open Leadership & Committee → People → Add block → Committee Member. Enter the name and position, add a licensed photo if available, and leave optional biography/LinkedIn blank unless confirmed.
- **Add a sponsor:** Open Sponsorship & Partners → Partners → Add block → Sponsor/Collaborator. Do not add a logo or claim sponsorship without approval.
- **Add a past-event highlight:** Open Highlights & Photos → Highlight Cards → Add block. Use a real event title, approved photo, date and public album URL.
- **Change the website look:** Select Page at the top. Choose a Global Color Palette, Spacing and Width preset. Each section also has Background, Vertical Spacing, Heading Alignment and Grid Layout controls.
- **Change a FAQ:** Contact & FAQ → FAQ Items. Changes appear after Publish.
- **Schedule events:** Use the official chapter Google Calendar. When connected, the website reads event dates and displays the next-event countdown automatically. Storyblok controls its *presentation*, not its event database.
- **Read/respond to inquiries:** Use the chapter's Formspree dashboard once forms are connected. Storyblok edits form introductions and labels, not the backend submissions.

## Publishing checklist

1. Check proper spelling, dates, officer roles and links.
2. Use authorized imagery only; don't upload unapproved logos or private Drive album links.
3. Test tablet/mobile preview if changing the visual layout.
4. Save then Publish; refreshing the public site after publication confirms the result.
5. Use Storyblok History/Versions if a change needs to be reversed.

## Safety and governance

- Never publish a Management or Preview API token.
- Keep access limited to approved committee members and use individual accounts where plan allows.
- Confirm public chapter information and official IEEE/Penn State logo usage with authorized advisors/administrators.
- Do not mislabel interim chapter leadership as formally elected.
- Do not create sample sponsors, speaker identities, fake events, or fabricated research claims.
